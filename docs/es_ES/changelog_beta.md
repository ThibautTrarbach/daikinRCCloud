# Changelog Daikin ONECTA
Todas las modificaciones notables de este plugin serán documentadas en esta página.

## [0.9.1] - 2025-12-05

### Información
- El Daemon 2.0.0 aún no está disponible correctamente. En los próximos días, le ofreceremos probarlo en modo alpha para evitar impactar su producción durante el período de calefacción

### Añadido
- Configuración de dependencias: posibilidad de elegir la rama o el commit a instalar
- Soporte para parámetros de polling (día/noche) para daemon 2.0.0+
- Soporte para modos de actualización después de acción para daemon 2.0.0+
- Compatibilidad con versiones V1 y V2 del daemon
- Internacionalización completa (FR, EN, ES, DE, IT)
- Enlace a la futura documentación y changelog

### Modificado
- Mejora en el manejo de mensajes MQTT
- Optimización de la creación de equipos

### Corregido
- Varias correcciones de errores
