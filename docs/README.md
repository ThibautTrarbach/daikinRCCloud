# Documentation Daikin ONECTA

Cette documentation est hébergée sur GitHub Pages.

## Structure

- `index.md` : Page d'accueil avec sélection de langue
- `fr_FR/` : Documentation en français
- `en_US/` : Documentation en anglais
- `es_ES/` : Documentation en espagnol
- `de_DE/` : Documentation en allemand
- `it_IT/` : Documentation en italien

Chaque dossier de langue contient :
- `index.md` : Documentation principale
- `changelog.md` : Historique des modifications

## Activation de GitHub Pages

1. Allez dans les **Settings** de votre dépôt GitHub
2. Dans la section **Pages**
3. Sous **Source**, sélectionnez :
   - **Branch** : `main` (ou `master`)
   - **Folder** : `/docs`
4. Cliquez sur **Save**

La documentation sera accessible à l'adresse :
`https://thibauttrarbach.github.io/daikinRCCloud/`

## Mise à jour

Pour mettre à jour la documentation, modifiez simplement les fichiers Markdown dans ce dossier et poussez les changements sur GitHub. GitHub Pages se mettra à jour automatiquement.
